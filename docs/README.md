## 项目速览

```
韭菜盘 (JCP)
├── 形态：Wails v2 桌面应用 + Web 服务模式（同一套代码）
├── 技术栈：Go 1.24 + React 18 + TypeScript + Vite + TailwindCSS
├── 数据源：通达信协议（行情）、东方财富（F10）、财联社（快讯）、多平台（舆情）
├── 模型接入：OpenAI 兼容 / Gemini / Vertex AI / Anthropic
└── 扩展能力：MCP（Model Context Protocol）工具接入
```

**核心能力**

- 多 Agent 智库：多个专家角色协作讨论，多维度分析
- 实时行情：K 线（5分/日/周/月）、五档盘口、大盘指数、资金流、龙虎榜
- 基本面 F10：公司概况、财务报表、估值、机构持股、行业对比等 20+ 项
- 智能记忆：按股票隔离的长期记忆，AI 记住历史讨论与关键结论
- 舆情研报：全网热搜聚合、券商研报检索与分析
- 策略管理：可视化配置专家组合，支持 AI 自动生成策略
