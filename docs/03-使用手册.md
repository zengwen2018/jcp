# 03 · 使用手册

## 1. 界面总览

```
┌──────────────┬───────────────────────────┬──────────────────┐
│              │                           │                  │
│  自选股列表   │      K 线图表区            │   AI 智库讨论室   │
│  + 大盘指数   │   （分时/日K/周K/月K）      │   （多专家讨论）    │
│              │                           │                  │
│  搜索框       │   盘口五档 / 涨跌榜        │   @ 提及专家       │
│  持仓信息     │   F10 基本面面板           │   输入框 + 发送     │
│              │                           │                  │
└──────────────┴───────────────────────────┴──────────────────┘
```

三个区域可拖拽调整宽度，布局自动持久化。

## 2. 核心功能

### 2.1 自选股与行情

**添加自选股**：左上角搜索框输入代码或名称（支持 `600000`、`浦发`、`sh600000`），搜索结果点击加入。

**K 线周期**：图表区顶部切换 —— 分时（1m）/ 日K / 周K / 月K。

**盘口五档**：图表下方显示买卖五档与逐笔成交。

**持仓信息**：在讨论区可记录该股票的持仓（股数、成本价），AI 分析时会纳入成本视角。

**大盘指数**：左侧面板顶部显示上证指数、深证成指、创业板指实时点位。

### 2.2 F10 基本面

在个股视图中打开 F10 面板，包含 20+ 个维度：

| 分类 | 内容 |
|------|------|
| 公司 | 公司概况、上市信息、主营业务、关键人员 |
| 财务 | 利润表/资产负债表/现金流量表、主要财务指标（年度+季度） |
| 估值 | PE/PB/PS/PCF/PEG、市值、换手率；支持 1/3/5/10 年趋势 |
| 股东 | 股东户数、增减持、机构持股、实控人、股权质押、限售解禁、回购 |
| 行业 | 行业分类、可比公司、同行估值与经营指标对比 |
| 经营 | 业务构成、经营评述、分红与融资 |
| 题材 | 核心题材与所属板块（当前+历史） |

### 2.3 AI 智库（多 Agent 讨论）

这是 JCP 的核心功能。

#### 提问方式

在右侧输入框输入问题，发送。**@ 某位专家** 可以定向提问：

```
@技术面分析师 现在这个位置能追吗？
@基本面研究员 这个估值算便宜吗？
```

不带 @ 时，由"小韭菜"（Moderator）根据问题意图选择专家。

#### 两种会议模式

| 模式 | 行为 | 适用 |
|------|------|------|
| `smart`（串行） | 专家依次发言，后面的能看到前面的观点 | 需要相互补充的综合分析 |
| `direct`（独立） | 各专家独立回答，互不可见 | 快速获取多视角 |

在策略配置里切换。

#### 失败处理

- 专家调用失败会**自动重试**（次数由 `AIRetryCount` 控制，默认见配置）
- 重试仍失败，界面提供「重试该专家」按钮
- 也可以「重试并继续」——跳过失败的专家，让剩余专家继续
- 或「放弃重试」——保留已有结论

#### 二次复核

开启 `EnableSecondReview` 后，会有一位复核专家对整体结论做交叉检验，输出最终判断。

#### 提示词增强

在专家配置界面点「增强提示词」，会用 LLM 优化角色描述，让专家定位更清晰。

### 2.4 策略管理

**策略**是一组专家的组合。

- **切换策略**：设置页或策略栏直接切换，立即生效
- **AI 生成策略**：描述你想要的分析风格（如"稳健价值投资派"），AI 自动生成包含多位专家的完整策略
- **专家增删改**：在策略里自由添加/移除专家、调整角色提示词与工具权限

**内置策略**开箱可用，建议先跑通再改写。

### 2.5 舆情热点

聚合微博、知乎、B站、百度、抖音、头条等平台的实时热搜。面板按平台切换查看。

### 2.6 研报服务

查询券商研报列表（评级、研究员、预测 EPS/PE），可进一步获取正文内容并交给 AI 分析。

### 2.7 龙虎榜与榜单

- 龙虎榜：上榜股票、净买入金额、买卖金额、上榜原因；可下钻到营业部明细
- 盘口异动榜：涨速、跌速、涨跌幅、资金、换手
- 板块资金流：行业/概念/地域排行
- 板块龙头：综合涨跌幅与主力资金的龙头候选

## 4. MCP 扩展

通过 MCP（Model Context Protocol）接入外部工具，无需改代码。

### 支持的传输方式

| 方式 | 说明 |
|------|------|
| `http` | HTTP 服务端点 |
| `sse` | SSE 服务端点 |
| `command` | 本地命令（MCP Server 进程） |

### 配置流程

设置 → MCP 服务器 → 添加：

1. 填写名称与传输方式
2. `http`/`sse` 填 URL；`command` 填可执行文件路径与参数
3. 点「测试连接」验证
4. 在专家配置里把该服务器分配给需要的专家

### 注意

- `command` 类型的 MCP 会在**服务器本地**启动进程。容器部署时需确保对应运行时已安装
- MCP 工具可被加入专家的 `Tools` 白名单，与内置工具同等使用

## 5. 记忆系统

开启后（`Memory.Enabled`），AI 会记住历史讨论。

| 记忆类型 | 说明 |
|---------|------|
| 近期对话轮次 | 最近 N 轮原始对话（`MaxRecentRounds`） |
| 关键事实 | 讨论中提炼的事实要点（`MaxKeyFacts`） |
| 历史摘要 | 压缩后的对话摘要（`MaxSummaryLength`） |

存储位置：`memories/<股票代码>.json`，**按股票隔离**——讨论浦发银行不会影响平安银行。

记忆压缩可指定独立模型（`Memory.AIConfigID`），用便宜模型跑摘要能省成本。

触发压缩的阈值：`CompressThreshold`。

## 6. OpenClaw 集成

内置的 OpenClaw 服务在设置里可启用，它提供额外的 AI 分析能力（HTTP 服务形式，带自己的 API Key 与端口）。

启用后配置 `OpenClaw.Enabled`、`OpenClaw.Port`、`OpenClaw.APIKey`。服务启动时若已启用会自动拉起，配置变更时热重载。

## 7. 提示词编写建议

专家的 `Instruction` 决定分析质量。建议包含四要素：

```
角色定位：你是专注于技术面分析的资深分析师
分析框架：结合均线系统、量价背离、关键支撑压力位
关注重点：短期趋势与买卖时点，忽略长期价值判断
输出风格：结论先行，给出明确的操作建议和风险提示
```

反例（太笼统）：

```
你是一个股票分析师
```
